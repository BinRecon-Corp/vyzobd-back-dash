# Back-Office User Management Guide

## Overview
The Users page (`/admin/users`) enables Super Administrators to manage back-office staff accounts, assign RBAC roles, trigger administrative password resets, toggle account status (Active/Suspended), and force logout active sessions.

## Key Capabilities
- **Create Staff User**: Assign email, name, role, and temporary password.
- **Role Assignment**: Reassign staff permissions dynamically.
- **Force Session Revocation**: Terminate active refresh tokens for compromised accounts.
