# Admin Dashboard User Guide

## Overview
The Admin Dashboard (`/admin`) provides real-time business performance visibility, key metric KPIs, order volume charts, top-selling products, and quick access action widgets.

## Key UI Sections
1. **KPI Scorecard**: Total Revenue, Total Orders, Active Customers, Average Order Value (AOV).
2. **Sales Analytics Chart**: Time-series chart rendering revenue and order metrics (Recharts).
3. **Recent Orders Feed**: Quick view table listing latest order activity and quick link to OMS details.
4. **Top Products & Inventory Alerts**: Highlights low-stock items requiring inventory adjustment.
