# Platform Settings Interface Guide

## Overview
The Settings hub (`/admin/settings`) controls platform configuration across multiple tabs:
- **General & Branding**: Store name, logo upload, favicon, currency code.
- **SEO Defaults**: Default meta tags, social share images, Google Search Console verification.
- **SMTP Email**: Host, port, credentials, and test email dispatcher.
- **Analytics**: GA4 Measurement ID, API secret, Google Cloud service account JSON.
- **Security**: JWT expiry policies, maximum login retry attempts, rate-limiting limits.
- **Shipping & Tax**: Shipping zone fee rules and regional tax percentages.
