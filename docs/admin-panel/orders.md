# Order Management System (OMS) Guide

## Overview
The OMS page (`/admin/orders`) allows fulfillment staff to manage customer orders through their lifecycle.

## OMS Features
- Filter orders by status (`PENDING`, `PROCESSING`, `SHIPPED`, `DELIVERED`, `CANCELLED`).
- View line item details, customer address, and payment status.
- Add staff internal notes and inspect order audit timeline events.
- Trigger fulfillment shipment creation or cancel unfulfilled orders.
